# SharePoint 構成方式の比較デモ（方式A／B／C）

文書分類体系（大分類・中分類）を SharePoint Online にどう落とすか、
**3つの構成方式を同じ画面・同じ権限のまま切り替えて比較する**ためのデモです。

> 掲載データはすべてサンプルです。組織名・担当者名・取引先名は架空のものに置き換えています。

## 3つの方式

| | サイトの単位 | ライブラリの単位 | 本数 |
|---|---|---|---|
| **方式A｜現行案** | 業務区分（13） | 各部署のフォルダ名 | 92 |
| **方式B｜中分類** | 大分類（14） | 中分類（104） | 104 |
| **方式C｜折衷** | 大分類（14） | 中分類のうち文書があるもの | 76 |

方式Aは中分類をメタデータの列としてのみ持ちます。方式B／Cはライブラリそのものが中分類なので、
**配下のフォルダは必ず1つの中分類に属します（1:N が構造で保証される）**。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要・外部通信なし）。

- 画面上部の **構成方式** タブで A／B／C を切り替え
- 右上のアバターをクリックすると **表示ユーザー（部署・役職）** が切り替わります
- `G` キー、または `?guide=1` で画面の各要素の説明を重ねて表示します

### URL パラメータ

| パラメータ | 値 | 例 |
|---|---|---|
| `plan` | `A` / `B` / `C` | `?plan=B` |
| `user` | `ALL`（全社管理者）／各部署／`L5` | `?user=SEI` |
| `guide` | `1` で説明オーバーレイ | `?guide=1` |

組み合わせ可： `?plan=C&user=SEI`

## 権限の考え方

- 権限は **ライブラリ単位**。フォルダ単位の権限は使いません
- 各ライブラリに **公開範囲**（閲覧できる部署の一覧）を持たせ、先頭が主管部署＝更新可
- 機密レベルは L2（全社共有）／L3（公開範囲の部署）／L4（そのうえで管理職のみ）／L5（個別指定）
- **権限のないものは鍵アイコンではなく、一覧から消えます**（本番の対象ユーザー設定と同じ挙動）

方式B／Cでは同じ中分類に複数部署の文書が集まるため、機密レベルは
**厳しい方に引き上げられます**。切り替えて比べると挙動が確認できます。
